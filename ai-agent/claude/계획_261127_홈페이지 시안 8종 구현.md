> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 크몽 상세페이지 이미지로 팔 업종별 원페이지 홈페이지 시안 8개(T-01~T-08)를 새 비공개 저장소 `homepage-templates`에 만들고, 시안마다 1280px·375px 크몽용 스크린샷을 뽑는다.

**Architecture:** 시안 하나 = 완결된 폴더 하나(`index.html`, `style.css`, `main.js`, `README.md`, `assets/`). 폴더끼리 아무것도 공유하지 않는다. 품질은 저장소의 Python 도구 3개로 지킨다: `scripts/check.py`(규칙 정적 검사), `scripts/shot.py`(CDP 전체 페이지 스크린샷 + 가로 넘침 검사), `scripts/fetch_photos.py`(사진 목록대로 내려받고 출처 파일 생성). 도구는 표준 라이브러리만 쓰고 `unittest`로 검증한다.

**Tech Stack:** HTML, CSS(변수·Flex·Grid·미디어쿼리), 바닐라 JS(모듈 아님), Pretendard(jsDelivr), Google Fonts(Noto Serif KR, Gowun Batang, Nanum Pen Script, Black Han Sans), Python 3(`py -3`, 표준 라이브러리), 헤드리스 Edge + CDP

**Spec:** `ai-agent/claude/기획_261127_홈페이지 시안 8종 v0.1.md` (분위기 견본 `ai-agent/claude/견본_261127_홈페이지 시안 8종 분위기.html`, 상위 결정 D-13)

- Git 설정은 portfolio-site처럼 저장소 설정으로만: `user.name`·`user.email`은 portfolio-site 저장소 값 그대로, `core.autocrlf=input`. 기본 브랜치 `main`. 커밋 메시지 Conventional Commits
- 파일 최상단 헤더: 작성일, 파일 위치, 목적. 새 코드에 *왜*를 한두 줄 주석으로 (운영자 학습용)
- HTML에 `style=""` 금지. 색 값(`#`, `rgb(`, `hsl(`)은 `style.css`의 `:root` 블록 안에만. 이미지 `alt`, 버튼 `aria-label`, 시맨틱 태그(`header`, `nav`, `main`, `section`, `footer`)
- 연락처는 누가 봐도 가짜: 전화 `000-0000-0000`, 주소 "OO시 OO구 OO로 00", 이메일·SNS `href="#"`. 사업자 정보 "사업자등록번호 000-00-00000"
- 사진 속 인물에 이름을 붙이지 않는다: "OOO 대표원장", "OOO 변호사", "OOO 코치"
- 지어낸 후기·별점·성공사례 금지. "후기", "리뷰", "성공사례", "★" 글자를 쓰지 않는다
- `<meta name="robots">` 넣지 않는다
- 사진: Unsplash에서 내려받아 `assets/`에(핫링크 금지). 큰 사진 가로 1600px, 작은 사진 800px, JPEG 품질 80. 출처는 `assets/CREDITS.md`. **8개 시안 사진 목록을 한 번에 보여 주고 한 번에 허락받은 뒤 내려받는다**
- 밝고 선명한 사진. 어두운 사진 위 글자에만 그라데이션 (T-01, T-08은 의도된 어두운 분위기)
- 구역 `id`는 8개 모두 같다: `top`(첫 화면), `about`, `services`, `gallery`, `trust`, `contact`. 메뉴 글자는 시안마다 다르다
- 구역마다 바꿀 곳 주석 `<!-- 바꿀 곳: ... -->`. 시안 폴더 `README.md`에 고객 맞춤 순서: 상호 → 색 → 사진 → 글 → 연락처
- 휴대폰 기준 너비 768px 미만. 확인 너비 1280px, 375px. 375px에서 `document.documentElement.scrollWidth <= 375`
- 분위기(색·글꼴·첫 화면 배치·견본 상호·견본 사진 ID)는 기획서 §5와 견본 파일을 그대로 따른다

## Review Focus

1. **고객이 상호·제목을 더 긴 글로 바꿨을 때**: 375px 첫 화면에서 글이 넘치거나 사진과 겹치면 안 된다. 제목에 `white-space: nowrap`을 쓰지 않고 `word-break: keep-all`로 줄을 바꾼다. → 각 시안 작업의 "긴 글 확인" 단계
2. **메뉴를 눌러 이동했을 때 위에 붙은 메뉴가 구역 제목을 가리는 것**: 모든 `section`에 `scroll-margin-top`. → `check.py` 규칙 `scroll-margin`
3. **휴대폰 ☰ 메뉴**: 메뉴 항목을 누르면 닫히고, Esc로 닫히고, `aria-expanded`가 맞게 바뀐다. → Task 4의 메뉴 확인 단계 (같은 `main.js`를 8개가 복사해 쓴다)
4. **구글 폰트·Pretendard가 안 불러와질 때**: 대체 글꼴로도 배치가 무너지지 않는다. 모든 `font-family`에 `sans-serif` 또는 `serif` 대체. → `check.py` 규칙 `font-fallback`
5. **사진이 느리게 뜰 때 화면이 덜컹거리는 것**: 모든 `<img>`에 `width`·`height` 속성, 첫 화면 아래 사진은 `loading="lazy"`. → `check.py` 규칙 `img-size`
