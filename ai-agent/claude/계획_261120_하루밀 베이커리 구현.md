# 하루밀 베이커리 데모 구현 계획

**파일 위치**: `ai-agent/claude/계획_261120_하루밀 베이커리 구현.md`
**작성일**: 2026-11-20

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 가상의 동네 빵집 "하루밀 베이커리" 원페이지 데모를 `src/demos/haru-bakery/`에 만들고, 포트폴리오 사례 목록에 라이브 데모 카드로 연결한다.

**Architecture:** 빌드 도구 없는 정적 페이지. 데모 전용 HTML·CSS·JS와 사진을 한 폴더에 두어 포트폴리오 스타일과 섞이지 않게 한다. 사진은 Unsplash CDN의 크기 조절 주소(`?w=1600&q=80&fm=jpg`)로 이미 줄인 파일을 내려받는다(이 PC에는 Pillow가 없다).

**Tech Stack:** HTML, CSS(변수·Flex·Grid·미디어쿼리), 바닐라 JS, Google Fonts(Noto Serif KR), Pretendard(jsDelivr)

**Spec:** `ai-agent/claude/기획_261120_카페 데모 하루밀 베이커리 v0.1.md`

## Global Constraints

- 파일 최상단 헤더: 작성일, 파일 위치, 목적
- HTML에 `style=""` 금지. 색은 `css/style.css`의 `:root` 변수만 쓴다
- 이미지 `alt`, 버튼 `aria-label`, 시맨틱 태그(`header`, `main`, `section`, `footer`)
- 연락처는 누가 봐도 가짜: 전화 `000-0000-0000`, 주소 "OO시 OO구 빵굽는길 00", 인스타 `href="#"`
- 바닥글에 "포트폴리오용 데모 사이트입니다. 가게·메뉴·연락처는 모두 지어낸 예시입니다." 문구, 사진 출처, 포트폴리오(`../../index.html`)로 돌아가기 링크
- 분위기: 크림 배경, 진한 갈색 글씨, 제목 Noto Serif KR, 본문 Pretendard
- 사진: 가로 최대 1600px, 한 장 300KB 이하, `assets/`에 저장, 핫링크 금지
- 확인 너비: 1280px, 375px
- 새 코드·큰 변경에는 *왜*를 한두 줄 주석으로 남긴다 (운영자 학습용)

## Review Focus

1. **휴대폰에서 사진이 많아 느림**: 첫 화면 아래 이미지는 `loading="lazy"`, 모든 `<img>`에 `width`·`height`를 넣어 화면이 덜컥거리지 않아야 한다 → Task 2 확인 단계에서 점검
2. **375px에서 가로 스크롤**: 메뉴 6개 그리드·시간표가 넘치지 않아야 한다 → Task 2에서 `document.documentElement.scrollWidth <= innerWidth` 확인
3. **상단 메뉴가 섹션 제목을 가림**: 메뉴 링크로 이동했을 때 제목이 고정 헤더 아래 보여야 한다 → Task 2에서 `scroll-padding-top` 확인
4. **모바일 메뉴가 링크를 누른 뒤에도 열려 있음**: 링크를 누르면 닫혀야 한다 → Task 2 확인
5. **포트폴리오에서 데모로 가는 상대 경로가 배포 후 깨짐**: `demos/haru-bakery/`(끝 슬래시 포함) 상대 경로를 쓴다 → Task 3에서 로컬 서버로 클릭 확인
