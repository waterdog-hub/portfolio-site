# 카페·베이커리 데모 기획: 하루밀 베이커리

**파일 위치**: `ai-agent/claude/기획_261120_카페 데모 하루밀 베이커리 v0.1.md`
**작성일**: 2026-11-20
**버전**: v0.1
**설명**: 포트폴리오에 넣을 가상의 동네 빵집 홈페이지 데모의 목표, 범위, 화면 구성, 결정 기록. 상위 기획서의 R-10, D-06에 대응한다.
**메모 (2026-11-20)**: 처음 구상한 앙버터·소금빵은 무료 사진에서 같은 빵을 찾기 어려워 바게트 샌드위치·버터 모닝빵으로 이름을 바꿨다 (운영자 결정). 이 문서의 메뉴 언급은 바뀐 이름을 따른다.

---

## 1. 목표와 이유

- 지금 포트폴리오 사례 3건(remodel-link, 잇다, smart-voca)은 모두 회원제 서비스다. 그래서 "우리 가게 홈페이지"를 맡기려는 의뢰인이 보기에 비슷한 예시가 없다(상위 기획서 §5-2).
- 운영자가 받고 싶은 업종은 **카페·베이커리**와 **미용실**이다. 이 문서는 그중 카페·베이커리 데모를 다룬다.
- 성공 기준: 카페·베이커리 사장님이 데모를 보고 "우리 가게도 이렇게 만들어 달라"고 플랫폼으로 문의하는 것.

## 2. 범위

| 구분 | 포함 | 제외 |
|------|------|------|
| 성격 | 보기만 하는 원페이지 홈페이지 | 예약·주문·게시판 같은 서버 기능 (백엔드 사례는 미용실 데모가 맡는다) |
| 가게 | 지어낸 가게 "하루밀 베이커리" | 실제 가게 |
| 사진 | 무료 사진 사이트(Unsplash 등)의 상업 이용 가능한 사진 | AI 이미지, 직접 촬영 |

**안티 목표** (기술적으로 돌아가도 실패로 보는 것)
- 실제 가게나 실제 연락처로 오해받는 것: 전화·주소는 누가 봐도 가짜로 둔다(D-02)
- 사진이 흐리거나 무거워 휴대폰에서 느리게 뜨는 것
- 포트폴리오 사이트와 같은 화이트 템플릿처럼 보이는 것: 업종 맞춤 디자인이라는 점이 드러나야 한다

| B-02 | 첫 화면 | 큰 빵 사진, "매일 아침, 천천히 구운 빵", [오늘의 빵 보기] 버튼 |

## 4. 만드는 방법

### 접근 비교 (운영자가 ①을 골랐다)

| 안 | 내용 | 장점 | 단점 |
|----|------|------|------|
| **① 포트폴리오 안 폴더** | `src/demos/haru-bakery/` | 배포·저장소가 하나, 포트폴리오에서 바로 연결 | 주소에 데모라는 게 드러남 (숨길 필요 없음) |
| ② 별도 프로젝트 | 새 저장소와 Netlify 사이트 | 독립된 주소 | 저장소·배포 두 벌, 정적 페이지라 나눌 이유 적음 |

미용실 데모는 예약 서버가 필요해 ②처럼 따로 만든다.

### 정해진 것

- 순수 HTML·CSS에 최소한의 JS(모바일 메뉴)만 쓴다(D-01). 프로젝트 코드 작성 규칙(파일 헤더, `style=""` 금지, 색은 `:root` 변수만 사용, 접근성 기본)을 그대로 따른다.
- 파일 구조:
  ```
  src/demos/haru-bakery/
  ├── index.html
  ├── css/style.css     # 데모 전용 스타일, 포트폴리오 style.css와 섞지 않는다
  ├── js/main.js        # 모바일 메뉴
  └── assets/           # 내려받아 줄인 사진
  ```
- 사진은 내려받아 줄인 뒤(가로 최대 1600px, 웹용 JPG 또는 WebP) `assets/`에 넣는다. 외부 사진을 직접 불러오는 방식(핫링크)은 쓰지 않는다. 내려받기 전에 사진 목록과 출처를 운영자에게 보여 주고 허락을 받는다.
- 포트폴리오 `index.html` 사례 목록에 카드를 하나 더하고 "라이브 데모" 링크를 단다.
- 데스크톱(1280px)과 휴대폰(375px)에서 확인한다.

### 만드는 사람이 정할 것

- 색 값과 글꼴 조합의 세부 (시안 A 기준: 크림 배경, 진한 갈색 글씨, 제목은 Noto Serif KR, 본문은 Pretendard)
- 메뉴 이름·가격·소개 문구 (지어낸 내용, 자연스러운 동네 빵집 수준)
- 사진 고르기 (같은 톤으로 맞춘다)
- 포트폴리오 카드의 위치와 스크린샷 (카드에 쓸 데모 스크린샷 1280·375도 찍는다)
