# 바른길 학원 데모 구현 계획

**파일 위치**: `ai-agent/claude/계획_261121_바른길 학원 구현.md`
**작성일**: 2026-11-21

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 가상의 초·중등 보습학원 "바른길 학원"의 학부모 화면(상담 신청)과 원장님 화면(상담 관리)을 `src/demos/bareun-academy/`에 서버 없이 만들고, 포트폴리오에 라이브 데모 카드로 연결한다.

**Architecture:** 빌드 도구 없는 정적 페이지 2장(`index.html`, `owner.html`). 저장·예시 데이터·규칙은 DOM을 모르는 ES 모듈 `js/store.js` 하나에 모아 Node 내장 테스트(`node --test`)로 검증하고, 화면 스크립트(`main.js`, `owner.js`)는 store를 불러 그리기만 한다. 데이터는 방문자 브라우저 localStorage에만 둔다.

**Tech Stack:** HTML, CSS(변수·Flex·Grid·미디어쿼리), 바닐라 JS(ES 모듈), localStorage, Pretendard(jsDelivr), Node 26 `node:test`(개발용, 배포되지 않음)

**Spec:** `ai-agent/claude/기획_261121_학원 데모 바른길 학원 v0.1.md` (상위 결정 D-09, D-10)

## Global Constraints

- 파일 최상단 헤더: 작성일, 파일 위치, 목적 (HTML은 `<!-- -->`, CSS·JS는 주석). 새 코드에는 *왜*를 한두 줄 주석으로 (운영자 학습용)
- HTML에 `style=""` 금지. 색은 `css/style.css` 맨 위 `:root` 변수만. 이미지 `alt`, 버튼 `aria-label`, 시맨틱 태그(`header`, `main`, `section`, `article`, `footer`)
- 사용자가 넣은 글(이름·문의·메모)은 화면에 `textContent`로만 넣는다. 사용자 값을 `innerHTML`에 넣지 않는다
- 분위기: 시안 A 신뢰 네이비(주색 `#1f3a68` 계열, 흰색·옅은 남색 배경 `#f3f6fb` 계열, 진한 글씨 `#14233f` 계열) + 시안 C 시간표 줄. 남은 자리 강조는 주황 계열 한 색. 글꼴은 Pretendard 하나. 본문 글자 대비 WCAG AA(4.5:1)
- 연락처는 누가 봐도 가짜: 전화 `000-0000-0000`, 주소 "OO시 OO구 OO로 00"
- 모든 화면 위쪽 데모 띠: "포트폴리오용 데모예요 · 학부모 화면 / 원장님 화면". 바닥글: "포트폴리오용 데모 사이트입니다. 학원·강사·연락처는 모두 지어낸 예시입니다.", 사진 출처, 포트폴리오(`../../index.html`)로 돌아가기
- `<meta name="robots" content="noindex">`
- localStorage 키 `bareun-academy-demo-v1` (다른 데모와 겹치지 않게). 수명 24시간. 방문자가 넣는 신청 20건까지
- 상태 값: `new`(새 신청), `contacted`(연락함), `enrolled`(등록), `onhold`(보류). 어느 상태에서든 다른 상태로 바꿀 수 있다
- 폼 기본값 "예시 이름"·"000-0000-0000", 안내 "실제 정보를 넣지 마세요". 전화번호는 숫자와 `-`만, 9~13자
- 사진: 내려받아 줄여 `assets/`에(핫링크 금지), 한 장 300KB 이하, 내려받기 전에 운영자 허락, 출처 `assets/CREDITS.md`. 강사는 사진 대신 이니셜 원형
- 화면 확인은 로컬 서버로 한다: `py -3 -m http.server 8000 -d src` 후 `http://localhost:8000/demos/bareun-academy/` (ES 모듈은 `file://`로 열면 동작하지 않는다)
- 확인 너비 1280px, 375px. 375px에서 `document.documentElement.scrollWidth <= innerWidth`
- 테스트: 저장소 루트에서 `node --test tests/` (테스트 파일은 `src/` 밖이라 배포되지 않는다)

## Review Focus

1. **저장된 값이 깨졌거나 예전 형식임** (JSON 파싱 실패, `version` 다름, `inquiries`가 배열이 아님): 오류 없이 예시 데이터로 다시 시작해야 한다 → Task 1 테스트 `loadState_corrupt_resets`
2. **원장님 화면을 먼저 엶** (학부모 화면을 거치지 않음): 빈 화면이 아니라 예시 신청이 보여야 한다 → Task 1 테스트(저장소가 비면 예시 생성) + Task 4 확인 단계
3. **이름·문의에 HTML을 넣음** (`<img src=x onerror=alert(1)>`): 글자 그대로 보이고 실행되지 않아야 한다 → Task 4 확인 단계
4. **두 탭을 나란히 엶**: 학부모 탭에서 신청하면 원장님 탭 목록이 새로 고침 없이 바뀌어야 한다 → Task 4 확인 단계 (`storage` 이벤트)
5. **신청 버튼을 빠르게 두 번 누름**: 신청이 두 건 생기면 안 된다 → Task 3 확인 단계 (보내는 동안 버튼 `disabled`)
