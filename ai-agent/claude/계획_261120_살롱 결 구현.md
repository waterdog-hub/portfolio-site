> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 가상의 미용실 "살롱 결"의 손님 예약 화면과 사장님 관리 화면을 FastAPI 별도 프로젝트 `C:\Users\PC2602\salon-demo`로 만들고, 방문자마다 따로 쓰는 예시 가게로 체험하게 한다.

**Tech Stack:** Python 3.15, FastAPI, SQLAlchemy 2, Jinja2, pydantic, uvicorn, tzdata, unittest(+FastAPI TestClient), SQLite, HTML·CSS·바닐라 JS, Noto Serif KR·Pretendard

1. **서버가 UTC로 도는데 "오늘"이 하루 어긋남**: 배포 서버는 보통 UTC다. 한국 시각 23:30에 들어온 사람에게 "오늘"은 한국 날짜여야 한다 → Task 3에 시각을 `2026-11-20 23:30 KST`로 고정한 테스트
2. **같은 시간에 두 번 예약 신청**: 두 번째는 겹쳐 저장되지 않고 `409 SLOT_TAKEN` → Task 4 테스트
3. **다른 방문자의 예약 번호로 확정·취소 요청**: 남의 가게 데이터는 `404` → Task 5 테스트
4. **쿠키가 막힌 브라우저**: 요청마다 새 가게가 생겨 핵심 장면이 깨진다. 안내가 떠야 한다 → Task 2(쿠키 없는 두 요청이 다른 가게) + Task 7(화면 안내) 확인
5. **휴대폰에서 예약 단계가 넘침·가려짐**: 375px에서 시간 버튼 줄이 가로 스크롤 없이 접히고, 고를 수 없는 시간은 눌리지 않아야 한다 → Task 7 브라우저 확인
